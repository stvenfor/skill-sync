# spec-orchestrator（本机个人 · 可选）

**独立会话双角色**之分析/验收侧（不改仓库）。默认写码流程请用 **`dual-agent-pipeline`（单会话子代理）**；仅当刻意拆成 Spec 聊天 + develop 聊天时使用本 Skill。

## 怎么用

1. **本会话（Spec）**：需求 → 用例 → AC → 生成交接包（不改仓库）。
2. **新开 develop 会话**：交接包全文粘贴为第一段消息 → 写码 → 按模板回报。
3. **回到 Spec 会话**：贴回报 + diff 信息 → 验收报告 / 返工清单。

触发词示例：**验收会话**、**Orchestrator**、**只出文档**、**监督 develop**。
