# I. 禁瞎猜 / 禁默认实现（硬门 · 不可绕过）

> 本 skill **必须保证**：不得瞎猜产品/逻辑，不得用默认实现交差。  
> 违反任一条 → **禁止 CODE**；已动码 → 主控 **REJECTED**；交卷缺证据字段 → 视为未完成。

## I.0 两条总则（写进每次派单首段）

1. **禁瞎猜**：入口参数、状态机、分支、API、字段、回写、权限失败、空态、交互时机——**只允许**来自逻辑源源码 / 已定稿分支表 / 用户书面裁定；禁止「按常识」「其它模块好像」「截图看起来像」。
2. **禁默认实现**：禁止占位/凑合交付——含系统弹框/图标顶替设计稿、假数据写死当成功路径、空实现/`TODO` 当已接通、自造 stub 页/默认文案/默认色值冒充源端、未入仓资源用灰块/系统图标/网图顶替、**把未证实的 OHOS API/三方库当已可用**。

「实现路径可提案」**只**指：真值已齐时，二选一工程落点（复用哪个 Compose 组件 / 是否 expect）；**绝不**包括自造产品行为。

## I.1 证据门槛（缺一即停）

| 要改什么 | 开改前必须已有 | 没有时怎么做 |
|---|---|---|
| 业务分支 / API / 回写 | §D 分支表行：入口→状态→成功/失败/空→源文件:符号 | `BLOCKED`；禁止猜接口 |
| UI 控件 / 弹框 / 图标 | §B 五行齐；资源非「缺失，停止」未裁定 | 停问；禁系统替代 |
| 动效 / Lottie | §B.4 | 停问 |
| 交互反馈 | `interaction-matrix` 对应行 | 停问 |
| 平台缝 | `expect-actual-inventory` 或接口+DI 方案已定 | 停问；禁随手 expect 全家桶 |
| 三方/OHOS API | CPF 文档或示例仓实证链接 | 停问或 DEFERRED |

CODE 派单与 RESULT **强制**写：

```text
NO_GUESS: yes
NO_DEFAULT: yes
EVIDENCE_LOGIC: <分支表行号或 源文件:符号>
EVIDENCE_UI: <对照点行号或 截图 page×state>   # 仅 UI 相关
SOURCE_SET: <commonMain|ohosMain|… 与白名单一致>
EXPECT_ACTUAL: none | <符号列表>
CPF_VERSION: <follow-notes 或具体钉扎>
```

## I.2 「默认实现」黑名单

1. 系统 AlertDialog / Material 默认 Dialog 顶产品弹框（规格未写「用系统」）
2. 系统图标 / 灰块 / 手绘 / 网图顶资源
3. 硬编码假列表、假成功码、假 token 当主路径「已通」
4. 只搭 Compose 壳、网络/回写空实现却报 `PASS_CODE`
5. 从「别的 feature 抄个大概」改文案当本模块逻辑
6. 分支表有失败/空态，只做了成功态
7. 用户未裁定的「缺失，停止」资源仍用占位交差
8. 无证据把 AndroidX 专有类型直接放进 `commonMain`
9. 无 EXIT 卡做 ArkTS→Kotlin 大爆炸重写（见 §L）

## I.3 与 FAST（§H）的关系

- FAST **不砍**证据门槛。
- 瘦表 / P0-only **仍须**对已列行有源码证据；未列入的行为 **不做**。

## I.4 停问话术

```text
未知：<具体行为>
已知证据：<源文件:符号 / 截图 / 无>
选项A：…（推荐：…）
选项B：…
在未选定前：BLOCKED，不改码
```

禁止：先实现再问「这样行吗」。

## I.5 主控拒收清单

- RESULT 无 `NO_GUESS` / `NO_DEFAULT` / 相关 `EVIDENCE_*` / 相关 `SOURCE_SET`
- diff 含黑名单占位且 TASK 未豁免
- 分支表失败/空态未实现却报逻辑完成
- 出现「先按默认」「临时 stub」仍标 PASS_*
