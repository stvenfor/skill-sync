# J. 多轮不过：退出门与换路（硬）

> 禁止同一主题无限 CODE↔DEVICE 空转。  
> **同主题** = 同一对照点行 / 同一 Must-fix 根因 / 同一 UI 区块（以 triage 标题为准）。

## J.0 轮次计数

| 轮次 | 定义 | 必须动作 |
|---|---|---|
| **R1** | 首轮 CODE 后 DEVICE/烟测未过 | 写清失败点；按 §I 证据返工 |
| **R2** | 同主题第二次未过 | **强制**出 `TRIAGE_<主题>.md`（根因、已试配方、**禁区**、几何三件套）；禁止再直接 DISPATCHED 散单 |
| **R3** | triage 后再改仍未过 | **触发退出门 J.1**；禁止派 R4 同思路 CODE |

烟测失败与满量 ≤1% 失败都计入轮次。换人改码不重置轮次。

## J.1 退出门（R3 必走，不可跳过）

主控停派同思路 CODE，向用户交一张 **EXIT 卡**（一次说清）：

```text
EXIT_GATE: <module> / <主题>
轮次: R3
已试: <R1/R2/R3 各一行：改了什么 → 仍差什么>
根因假设: <当前 triage 认定>
证据: <截图 page×state / 对照点行 / 源文件:符号>
推荐换路: <A/B/C 之一，见 J.2>
备选: <其余>
请选：换路编号 | 或书面授权再试一轮（须写新前提，不得重复旧配方）
在未选定前：ACTIVE=BLOCKED，不改码
```

用户未选 → 保持 BLOCKED。禁止「先再改一版你看看」。

## J.2 换路菜单（选一为主，可组合）

| 代号 | 何时用 | 具体动作 | 完成定义 |
|---|---|---|---|
| **A 攻前提** | 同一几何/皮配方试过仍翻车 | 重验真值：是否截错端、错态、错账号；是否对照点写错；是否应用系统组件规格 | 新真值书面裁定后，轮次清零从 R1 |
| **B 缩范围** | 主路径已可交、边角拖死整单 | 将该点标 `DEFERRED`：写清非目标、不进本模块 Done；主路径可单独 PASS_SMOKE | brief/对照表勾 DEFERRED；禁止假装齐 |
| **C 换实现族** | 鸿蒙组件能力撞墙（播放器/弹层/安全区） | 在**仓内已有范例**中另选落点（仍禁系统顶替、禁瞎猜）；对照点「鸿蒙落点」列改写并经用户点头 | 新落点行定稿后再 CODE；旧配方进禁区 |
| **D 升满量复盘** | 怀疑 FAST 瘦表漏态 | `SPEED=full`：补 P1 截图/对照行，全量相关态再验 | full 产物齐后再计一轮 |
| **E 人工产品裁定** | 三边冲突（截图≠逻辑≠设计） | 停问产品二选一；未裁定前冻结该行 | 裁定写入 Truth-ID；废止旧 MF |
| **F 拆出独立切片** | 业务残差与 UI 皮搅在一单 | 新开逻辑-only 或 UI-only TASK；原单禁再混改 | 两单各自验收，互不重置对方轮次 |

**禁止的「假换路」：** 只改 margin/字号再挂 R4；换执行人但不改前提；删真值凑绿。

## J.3 与 §E / triage / §I 的关系

- R2 triage 条文与 §E「同主题多轮打回先合并」一致；本层补 **R3 退出** 与 **换路菜单**。
- 换路仍受 §I 约束：换实现族 ≠ 允许 stub/默认实现。
- EXIT 未完结前，周报/进展不得写该主题「已对齐」。

## J.4 RESULT / ACTIVE 字段

同主题未过时 RESULT 增写：

```text
RETRY_ROUND: R1|R2|R3
TRIAGE_PATH: <若 R2+>
EXIT_GATE: pending|chosen:<A-F>|authorized_R4:<新前提一句话>
```

R3 且 `EXIT_GATE: pending` → ACTIVE 必须 `BLOCKED`。
