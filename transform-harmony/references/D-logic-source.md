## 4. 逻辑源端勘察（行为真值轨）

产出 `ios-logic/map.md` + `notes-state-machine.md`（名称可随源端改，内容不可少）：

1. 用户入口 → 路由/参数表
2. 主 VC/Presenter/VM（或等价）与子工厂
3. 网络：路径、字段、空/失败
4. 完成回写与上下游回调
5. 权限与错误路径
6. **派 CODE 前硬门**：`入口 → 状态/分支 → 成功/失败/空态 → 对应截图号`，且每行可回溯到 **源文件:符号**
7. 勘察结果填入 **§B 对照点表**（类名/资源路径级，禁止「类似弹框」）

### 4.1 与 §I 联锁（硬）

- 缺分支表或对照点表 → **停**，不准边写边猜。
- 分支表有、源码定位无 → 视为未齐，**禁止**用「按截图猜接口」补全。
- 只实现成功态、失败/空/权限路径空着 → **禁止**报逻辑轨完成。
- 交卷必须 `NO_GUESS: yes` + `EVIDENCE_LOGIC: …`（见 `references/I-no-guess-no-default.md`）。
