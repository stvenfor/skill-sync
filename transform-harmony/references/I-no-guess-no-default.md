# I. 禁瞎猜 / 禁默认实现（硬门 · 不可绕过）

> 本 skill **必须保证**：智能体不得瞎猜产品/逻辑，不得用默认实现交差。  
> 违反任一条 → **禁止 CODE**；已动码 → 主控 **REJECTED**；交卷缺证据字段 → 视为未完成。

## I.0 两条总则（写进每次派单首段）

1. **禁瞎猜**：凡入口参数、状态机、分支、API、字段、回写、权限失败、空态、交互时机——**只允许**来自逻辑源源码 / 已定稿分支表 / 用户书面裁定；禁止「按常识」「其它模块好像」「截图看起来像」。
2. **禁默认实现**：禁止用占位/凑合交付当完成——含系统弹框/图标顶替设计稿、假数据写死当成功路径、空 `then`/`TODO`/`FIXME` 当已接通、自造 stub 页/默认文案/默认色值冒充源端、未入仓资源用灰块/SymbolGlyph/网图顶替。

「实现路径可提案」**只**指：在**真值已齐**时，向用户二选一工程落点（复用哪个鸿蒙组件）；**绝不**包括自造产品行为或 UI 观感。

## I.1 证据门槛（缺一即停）

| 要改什么 | 开改前必须已有 | 没有时怎么做 |
|---|---|---|
| 业务分支 / API / 回写 | §D 分支表行：入口→状态→成功/失败/空→源文件:符号（可定位） | `BLOCKED` + 停问；**禁止**猜接口 |
| UI 控件 / 弹框 / 图标 | §B 对照点五行齐；资源非「缺失，停止」未裁定 | 停问；禁系统替代 |
| 动效 / Lottie | §B.4：触发态、资源路径、循环/帧 | 停问；禁随便播一个 |
| 交互反馈 | `interaction-matrix` 对应行 | 停问；禁自造 timing |

CODE 派单与 RESULT **强制**写：

```text
NO_GUESS: yes
NO_DEFAULT: yes
EVIDENCE_LOGIC: <分支表行号或 源文件:符号>
EVIDENCE_UI: <对照点行号或 截图 page×state>   # 仅 UI 相关改动
```

缺任一项（与本单相关）→ 主控直接 REJECTED。

## I.2 明确列入「默认实现」的黑名单

1. `AlertDialog` / `showDialog` / 系统 `prompt` 顶产品弹框（规格未写「用系统」）
2. `SymbolGlyph` / 系统图标 / 灰块 / 手绘 / 网图顶资源
3. 硬编码假列表、假成功码、假 token 当主路径「已通」
4. 只搭 UI 壳、网络/回写空实现却报 `PASS_CODE`
5. 从「别的 feature 抄个大概」改文案当本模块逻辑
6. 分支表有失败/空态，鸿蒙只做了成功态
7. 用户未裁定的「缺失，停止」资源仍用占位交差

## I.3 与 FAST（§H）的关系

- FAST **砍的是空等与过重文档**，**不砍**证据门槛。
- 禁止把「能默认则推进」理解成可猜产品；H.1 已改为：仅工程落点二选一且真值已齐。
- 瘦表 / P0-only **仍须**对已列行有源码证据；未列入的行为 **不做**，不是用默认行为填上。

## I.4 停问话术（强制形态）

未知产品对错时一次 ≤3，每条必须：

```text
未知：<具体行为>
已知证据：<源文件:符号 / 截图 / 无>
选项A：…（推荐：…）
选项B：…
在未选定前：BLOCKED，不改码
```

禁止：先实现再问「这样行吗」。

## I.5 主控拒收清单（一眼 REJECTED）

- RESULT 无 `NO_GUESS` / `NO_DEFAULT` / 相关 `EVIDENCE_*`
- diff 含黑名单占位且 TASK 未白名单豁免
- 分支表失败/空态未实现却报逻辑完成
- 聊天或 RESULT 出现「先按默认」「先猜一个」「临时 stub 以后再补」且仍标 PASS_*
